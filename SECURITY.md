# Security and Responsible Use

Media Dork Studio is a query-construction and search-results tool. It does not
probe hosts, bypass access controls, scrape Google, solve CAPTCHAs, or download
discovered files.

## Responsible use

- Use the application only for lawful research and systems/content you are
  authorized to assess.
- Treat indexed links as leads, not permission to access or redistribute data.
- Do not use the tool to seek credentials, secrets, authentication artifacts,
  private personal data, or other sensitive material.
- If you encounter exposed sensitive information, stop access, preserve minimal
  evidence, and notify the owner through an appropriate disclosure channel.

The Smart Strategy Advisor refuses to optimize plainly sensitive-data goals.
This guardrail is defense in depth, not a substitute for user judgment.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** workflow when available. Include the affected version,
reproduction steps, impact, and any suggested remediation. Do not include live
credentials, private data, or unnecessarily sensitive proof material.
